# Chui Kitchen — PWA สั่งวัตถุดิบในเครื่อง

เปิดเว็บ: https://salah1st.github.io/chui-kitchen-orders/

ใช้ HTML/CSS/JavaScript, Service Worker และ IndexedDB ไม่มี backend, Login, GitHub API, analytics หรือโค้ดจาก CDN ข้อมูลราคาและหน่วยที่ผู้ใช้แก้ไม่ถูกส่งขึ้น GitHub หรือบริการอื่น เว็บโฮสต์เฉพาะตัวแอปและรายการตั้งต้น

## ติดตั้งบน iPhone

1. เปิดลิงก์ใน Safari พร้อมอินเทอร์เน็ต รอข้อความ **พร้อมใช้ออฟไลน์**
2. แตะแชร์ → เพิ่มไปยังหน้าจอโฮม → เปิด Open as Web App หากมี → เพิ่ม
3. เปิดจากไอคอน Chui Kitchen พร้อมอินเทอร์เน็ตอีกครั้ง และรอข้อความพร้อมใช้ออฟไลน์ จากนั้นใช้งานผ่านไอคอนเดิม
4. เลือกวัตถุดิบ ปรับจำนวนครั้งละ 0.5 แล้วกด Export ด้านบน เพื่อคัดลอก แชร์ หรือดาวน์โหลดข้อความ

การเพิ่มไอคอนอย่างเดียวไม่ได้รับประกันว่าแอปพร้อมออฟไลน์ ต้องรอให้ Service Worker ติดตั้งและเก็บไฟล์ครบก่อน ปุ่มติดตั้งแอปมีคำแนะนำในหน้าเว็บ

## ราคาและหน่วย

รายการมาตรฐานทั่วไป 48 + MAKRO 39 รายการ เริ่มที่จำนวน 1 หน่วย, หน่วย “โล” และยังไม่มีราคา มูลค่าแสดง “—” จนระบุราคา ส่วนราคา 0 หมายถึงมูลค่า 0 บาท คำนวณเป็นสตางค์ ปัดมูลค่าต่อแถวเป็น 2 ตำแหน่ง

- คอมพิวเตอร์แก้คอลัมน์ราคาและหน่วยได้โดยตรง
- หน้าจอเล็กกว่า sm (640px) ซ่อนคอลัมน์ราคา/หน่วย แสดงตั้งแต่ 640px ขึ้นไป ส่วนสรุปด้านขวายังซ่อนเมื่อกว้างน้อยกว่า 1024px ทุกขนาดมีปุ่มดินสอข้างชื่อสำหรับเปิดหน้าต่างแก้ราคา/หน่วย
- ราคาและหน่วยของ 87 รายการมาตรฐานบันทึกอัตโนมัติใน IndexedDB ของเครื่องนี้ มีสถานะกำลังบันทึก/บันทึกไม่ได้ ไม่แสดงว่าสำเร็จจน transaction เสร็จ
- หากเปิดที่เก็บข้อมูลไม่ได้ ยังใช้รายการในหน้านี้และ Export สำรองได้ แต่ข้อมูลจะไม่ถาวร
- เปลี่ยนหน่วยไม่ได้แปลงราคาและจำนวนโดยอัตโนมัติ
- การเลือก จำนวนสั่งซื้อ และรายการกำหนดเองเป็นข้อมูลชั่วคราว รีเฟรช/เริ่มใหม่จะยกเลิกการเลือก ล้างรายการกำหนดเอง และคืนจำนวนเป็น 1 โดยไม่ล้างราคาและหน่วยมาตรฐาน
- ข้อมูลไม่ซิงก์ระหว่างเครื่องหรือระหว่างพื้นที่เก็บข้อมูลของ Safari กับแอปที่เพิ่มบนหน้าจอโฮม หากข้อมูลไม่ตามมา ให้ใช้สำรอง/นำเข้า JSON

## สำรองและนำเข้า JSON

กด **สำรอง JSON** เพื่อดาวน์โหลดข้อมูลราคาและหน่วยครบ 87 รายการ พร้อมชื่อสำหรับตรวจสอบ ไฟล์ไม่เก็บการเลือก จำนวนสั่งซื้อ หรือรายการกำหนดเอง เก็บในแอปไฟล์หรือส่งผ่าน AirDrop เพื่อย้ายไปอีกเครื่อง

กด **นำเข้า JSON** แล้วเลือกไฟล์สำรอง แอปตรวจ app/schema, รหัสครบ 87 รายการ, รหัสซ้ำ, ราคา, หน่วย และขนาดไฟล์ ก่อนแสดงจำนวนรายการให้ยืนยัน การนำเข้าจะแทนที่ราคา/หน่วยในเครื่องแบบ transaction เดียว ไม่เปลี่ยนรายการที่เลือกหรือจำนวนปัจจุบัน หากเขียนล้มเหลว ข้อมูลเก่าใน DB ยังคงเดิม

ข้อมูลเว็บอาจหายเมื่อล้างข้อมูล Safari, ถอนแอป หรือระบบจัดการพื้นที่เก็บข้อมูล ควรสำรองเป็น JSON เป็นระยะ และก่อนเปลี่ยนเครื่อง/เบราว์เซอร์/โดเมน

## Export รายการสั่งของ

เลือกแล้วกด **Export รายการ** ส่งออกเฉพาะรายการที่เลือก แยกหัวข้อทั่วไป / MAKRO / กำหนดเอง พร้อมจำนวน หน่วย มูลค่าต่อรายการ ยอดรวมแต่ละหมวด และยอดรวมทั้งหมด ใช้คำว่า “ครึ่ง” เมื่อมี .5 เช่น `กุยช่าย 1 โล ครึ่ง — 29.85 บาท` แชร์ผ่าน share sheet, ดาวน์โหลด .txt หรือคัดลอกได้ AirDrop ขึ้นอยู่กับระบบ/เบราว์เซอร์และต้องเลือกปลายทางเอง

มูลค่าอัปเดตทันทีเมื่อพิมพ์จำนวนที่ถูกต้องหรือปรับราคา โดยใช้ราคา × จำนวน ปัดเป็นสตางค์ต่อรายการก่อนรวมยอด รายการที่ยังไม่มีราคาจะระบุ “ยังไม่ระบุราคา” และแจ้งจำนวนรายการที่ยังไม่รวม แทนการนับเป็น 0 บาท ราคา 0 ที่ระบุจริงยังรวมเป็น 0 บาทตามปกติ

รายการกำหนดเองมีปุ่มไมค์ SpeechRecognition ภาษาไทย ใช้เมื่อกดเท่านั้น และอาจต้องเชื่อมอินเทอร์เน็ตหรือใช้บริการรับเสียงของเบราว์เซอร์ หากไม่รองรับให้ใช้ไมค์บนคีย์บอร์ด iPhone หรือพิมพ์ชื่อ การเลือก/ปรับจำนวน/ราคา/สำรอง/ส่งออกข้อความทำงานออฟไลน์ได้ การส่งข้อความไปแอปปลายทางและ AirDrop ขึ้นอยู่กับระบบ

## ไฟล์และการอัปเดต

ไฟล์เผยแพร่: `index.html`, `local-data.js`, `sw.js`, `manifest.webmanifest`, `icons/icon-192.png`, `icons/icon-512.png`, `.nojekyll` เท่านั้น ห้ามอัปโหลดไฟล์ JSON สำรองของผู้ใช้ขึ้น Repository

`sw.js` เก็บ app shell แบบ cache-first เมื่อมีรุ่นใหม่จะแสดง **อัปเดตแอป** ให้ยืนยันก่อนรีโหลด การอัปเดตไม่ล้าง IndexedDB แต่เริ่มรายการสั่งซื้อใหม่ ทุกครั้งที่แก้ไฟล์ app shell ให้เปลี่ยนชื่อ CACHE ใน `sw.js` และเผยแพร่ทุกไฟล์พร้อมกัน

PWA ไม่เรียก GitHub API หรือระบบ Login เพื่ออ่าน/บันทึกข้อมูล ราคาและหน่วยอยู่ใน IndexedDB ของผู้ใช้เท่านั้น

## ตรวจสอบ

```
node --test calculation.test.cjs local-data.test.cjs
```

ชุดทดสอบตรวจ backup round-trip, ข้อมูลที่ไม่ถูกต้อง, storage failure, cache ออฟไลน์, cache isolation และไฟล์ติดตั้ง การทดสอบบนเบราว์เซอร์ให้ลองแก้ราคา/หน่วยแล้วรีโหลด ตรวจจำนวนกลับเป็น 1, สำรอง/นำเข้า, ยกเลิกการนำเข้า, ตรวจมือถือ และเปิดจากหน้าจอโฮมขณะเปิดโหมดเครื่องบินบน iPhone จริง

การเปิดไฟล์ HTML ผ่าน Quick Look ในแอปไฟล์อาจไม่รัน JavaScript ให้เปิดผ่านลิงก์ HTTPS และติดตั้งตามขั้นตอนข้างต้น ตัวรัน LAN เก่า `serve_lan.py` เสิร์ฟเฉพาะ index.html จึงไม่ใช่ตัวรัน PWA นี้

การตรวจรุ่น PWA v1: ผ่านชุดทดสอบ 7 รายการ และตรวจเบราว์เซอร์จริงว่าราคา/หน่วยยังอยู่หลังรีโหลด แต่จำนวนกลับเป็น 1 และยกเลิกการเลือก, Export/คัดลอกไม่มีหัวหมวด, สำรอง JSON ครบ 87 รายการและนำเข้ากลับได้, ปุ่มเริ่มใหม่ไม่ล้างราคา, หน้าจอ 390px ไม่ล้นและซ่อนราคา/หน่วย/แผงขวา, ไม่มี console error ระบบแสดงพร้อมใช้ออฟไลน์หลัง cache ติดตั้งสำเร็จ ทดสอบการอ่าน cache ขณะเครือข่ายล้มเหลวด้วย test harness แล้ว แต่ยังไม่ได้ทดสอบติดตั้ง/เปิดโหมดเครื่องบินบน iPhone จริง
